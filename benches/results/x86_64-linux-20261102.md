# innr consumer-shape benchmarks: x86_64-linux

- CPU: AMD Ryzen 5 5600X 6-Core Processor
- Toolchain: rustc 1.91.1 (ed61e7d7e 2025-11-07)
- innr revision: 89f4c7f (tree copied without .git; set by hand)
- Settings: warm-up 300 ms, measurement 1000 ms per bench, NumKong enabled
- Benchmark wall time: 501 s
- Load average before / after: 1.01, 1.05, 1.11 / 2.07, 1.99, 1.60 (12 CPUs)
- Command: `benches/report.sh OUT.md` (see the script header)

Cells are Criterion medians. `innr_portable` is innr built with
`--no-default-features`; `innr_simd` is built with `--features simd`. `local_*`
columns are the consumer's own no-innr fallback, copied verbatim (sources
cited in the bench files). Speedups are other / innr, so above 1 means
innr is faster.

## A/A noise floor

The same kernel (`innr::dot`) and inputs under three names: copies 1 and 2
run back to back at the start of `consumer_pair`, copy 3 at its end, so the
spread (max / min - 1) includes drift across the run.
